# سایت کلاس فرهنگ و هنر — نسخه کامل اشتراکی

نسخه کامل سایت کلاس فرهنگ و هنر مامان علی، برای پایه‌های هفتم، هشتم و نهم.
برخلاف نسخه استاتیک قبلی، اینجا داده‌ها در **پایگاه داده مشترک Supabase** ذخیره می‌شوند؛
یعنی دانش‌آموز در گوشی خودش ارسال می‌کند و معلم در دستگاه خودش همان ارسال را می‌بیند.
رمز پنل معلم هم به‌صورت هش‌شده در دیتابیس ذخیره می‌شود، نه فقط در یک مرورگر.

## امکانات
- صفحه اصلی ساده و مستقیم، بدون لحن تبلیغاتی
- ارسال تکلیف: پایه، کلاس، نام، انتخاب تکلیف، عکس/PDF، توضیح خصوصی برای معلم، کد پیگیری با دکمه کپی
- پیگیری با کد: وضعیت، نمره ۰ تا ۲۰، نظر معلم، نشانه‌های روی عکس
- پنل معلم: ساخت تکلیف با مهلت شمسی، فیلتر/جستجو، آمار، نمره و بازخورد، نشانه‌گذاری روی عکس با پین شماره‌دار، آرشیو/حذف
- دیوار آثار زیبا: فقط آثار منتخب، بدون توضیح خصوصی و بدون نمره
- تب «متن‌های سایت»: ویرایش همه متن‌ها
- حالت تاریک/روشن متعادل، فارسی و راست‌چین، فونت وزیرمتن

## قدم ۱ — ساخت پروژه رایگان Supabase
1. به [supabase.com](https://supabase.com) بروید و با GitHub وارد شوید.
2. New project بسازید (نام: culture-art-class، رمز دیتابیس را نگه دارید).
3. چند دقیقه صبر کنید تا پروژه آماده شود.

## قدم ۲ — اجرای اسکیما
1. در داشبورد Supabase: SQL Editor → New query
2. محتوای فایل `supabase/schema.sql` را کپی و Run کنید.
3. بعد محتوای فایل `supabase/storage.sql` را هم Run کنید.
   یا در بخش Storage یک Bucket عمومی به نام `artwork` بسازید.

## قدم ۳ — گرفتن کلیدها
در Supabase: Settings → API
- Project URL را کپی کنید → `VITE_SUPABASE_URL`
- anon public key را کپی کنید → `VITE_SUPABASE_ANON_KEY`
- این کلید عمومی است و در کد فرانت‌اند قرار می‌گیرد؛ کلید `service_role` را هرگز اینجا نگذارید.

## قدم ۴ — اجرای محلی (اختیاری)
```bash
cp .env.example .env
# مقادیر واقعی را در .env بگذارید
npm install
npm run dev
```

## قدم ۵ — انتشار در Netlify (پیشنهادی)
1. کد را در GitHub بگذارید (ریپازیتوری `culture-art-class`).
2. در Netlify: Add new project → Import from GitHub → همان ریپازیتوری.
3. Build command: `npm run build` — Publish directory: `dist`
4. در Site settings → Environment variables، دو متغیر بالا را اضافه کنید.
5. Deploy. آدرس می‌شود مثل `culture-art-class.netlify.app`.
6. اگر بدون کلیدها Deploy کنید، سایت بالا می‌آید ولی بالای صفحه هشدار می‌دهد و داده‌ها فقط محلی می‌مانند.

## قدم ۵ (جایگزین) — انتشار در Vercel
1. در Vercel: Add New → Project → Import همان ریپازیتوری GitHub.
2. Framework Preset: Vite. Build Command: `npm run build`. Output: `dist`.
3. دو متغیر محیطی بالا را اضافه کنید و Deploy بزنید.

## قدم ۶ — تست بین دو دستگاه
1. در مرورگر خودتان وارد پنل معلم شوید و رمز تعیین کنید.
2. یک تکلیف بسازید.
3. در گوشی دیگر (یا مرورگر دیگر) به‌عنوان دانش‌آموز ارسال کنید و کد پیگیری را نگه دارید.
4. در پنل معلم همان ارسال را ببینید، نمره بدهید و با کد پیگیری چک کنید.

## محدودیت‌ها
- فایل‌های خیلی بزرگ ممکن است در Supabase Storage رایگان محدود شوند؛ عکس‌ها را قبل از آپلود کوچک کنید.
- امنیت این نسخه برای یک کلاس مدرسه طراحی شده است، نه برای داده حساس؛ RLS در اسکیما باز است و رمز معلم با هش SHA-256 در دیتابیس چک می‌شود.
- گوگل درایو ۵ ترابایتی علی در این نسخه مستقیم وصل نشده است؛ فایل‌ها در Storage خود Supabase می‌روند. اتصال مستقیم به Google Drive نیاز به OAuth جداگانه دارد.
