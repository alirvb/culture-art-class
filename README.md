# سایت کلاس فرهنگ و هنر — نسخه قابل‌استقرار

سایت فارسی و راست‌چین برای درس فرهنگ و هنر، پایه‌های هفتم، هشتم و نهم.
معلم: مادر علی. دانش‌آموزان تکلیف ارسال می‌کنند، معلم می‌بیند، نمره می‌دهد و آثار منتخب را در «دیوار آثار زیبا» نشان می‌دهد.

این بسته **بازسازی تمیز و مستقل** از روی توضیحات سایت است؛ کد دقیق آرتیفکت Muse نیست.

## چه چیزی داخل پوشه است؟

- `index.html` — کل سایت در یک فایل: HTML + CSS + JavaScript
- `netlify.toml` — تنظیم انتشار در Netlify
- `README.md` — همین راهنما

## امکانات

- صفحه اصلی ساده و مستقیم، بدون لحن تبلیغاتی / جذب مشتری
- ارسال تکلیف: پایه، کلاس (الف/ب/ج)، نام، انتخاب تکلیف، آپلود عکس یا PDF، توضیح خصوصی برای معلم، کد پیگیری با دکمه «کپی کد»
- پیگیری با کد: وضعیت، نمره، نظر معلم و نشانه‌های روی عکس
- پنل معلم: تعیین رمز در اولین ورود، ساخت تکلیف با مهلت (تاریخ شمسی نمایش داده می‌شود)، فیلتر و جستجو بر پایه/کلاس/تکلیف/وضعیت، آمار، مشاهده و دانلود اثر، نمره ۰ تا ۲۰ + بازخورد، تغییر وضعیت، آرشیو/حذف
- نشانه‌گذاری روی عکس: معلم روی عکس می‌زند، نشانه شماره‌دار می‌گذارد و یادداشت می‌نویسد؛ دانش‌آموز آن را در پیگیری می‌بیند
- دیوار آثار زیبا: فقط آثار منتخب، با نام دانش‌آموز، پایه و عنوان — **بدون توضیح خصوصی و بدون نمره**
- تب «متن‌های سایت» در پنل معلم: ویرایش همه متن‌ها، عنوان‌ها و موضوع‌ها + بازگردانی پیش‌فرض
- حالت تاریک/روشن با دکمه ماه/خورشید؛ در تاریک، کارت هیرو تیره می‌ماند ولی نقاشی ملایم دیده می‌شود (نه خیلی تاریک و زشت)
- طراحی شیک و مدرن آتلیه/گالری: عاجی، سبز تیره، طلایی مات، فونت وزیرمتن
- شروع خالی: هیچ تکلیف یا ارسال نمونه‌ای نیست؛ معلم اول یک تکلیف می‌سازد

## ⚠️ محدودیت مهم — حتماً بخوانید

این نسخه **استاتیک** است و داده‌ها فقط در `localStorage` همان مرورگر ذخیره می‌شوند:

- اگر دانش‌آموز در گوشی خودش ارسال کند، معلم در گوشی/کامپیوتر خودش آن را **نمی‌بیند**.
- هر مرورگر/دستگاه داده جداگانه دارد؛ همگام‌سازی بین دستگاه‌ها نیست.
- عکس‌ها به‌صورت Data URL در مرورگر ذخیره می‌شوند؛ عکس‌های خیلی بزرگ ممکن است حافظه مرورگر را پر کنند. PDF فقط نامش ذخیره می‌شود.
- رمز پنل معلم فقط در همان مرورگر است و امن نیست؛ برای نسخه واقعی رمز را در سرور نگه دارید.

پس این نسخه برای **تست، نمایش و انتشار نمایشی** خوب است، ولی برای استفاده واقعی کلاس (دانش‌آموزان در گوشی خودشان، معلم در دستگاه خودش) به نسخه اشتراکی نیاز دارید.

## برای نسخه واقعی و اشتراکی چه باید کرد؟

پیشنهاد: **Vercel + Supabase** (هر دو پلن رایگان دارند)

1. کد را به یک پروژه React/Next.js با بک‌اند تبدیل کنید، یا از همین منطق با Supabase استفاده کنید.
2. جدول‌ها: `assignments` ،`submissions` ،`annotations` ،`site_texts`
3. فایل‌ها را در Supabase Storage یا Google Drive (با ۵ ترابایت علی) ذخیره کنید.
4. بعد همان پروژه را روی Vercel منتشر کنید.

## انتشار همین نسخه استاتیک

### راه ۱ — Netlify Drop (سریع‌ترین، ۱ دقیقه)

1. به https://app.netlify.com/drop بروید
2. همین پوشه `culture-art-class` را بکشید و داخل صفحه رها کنید
3. یک آدرس رایگان می‌گیرید، مثل `https://culture-art-class.netlify.app`
4. برای تغییر، پوشه را دوباره رها کنید

### راه ۲ — GitHub + Netlify (پیشنهادی)

1. در GitHub یک ریپازیتوری جدید بسازید، مثلاً `culture-art-class`
2. فایل‌های همین پوشه (`index.html` ،`netlify.toml` ،`README.md`) را در آن آپلود کنید
3. در Netlify: Add new project → Import a Git repository → GitHub → همان ریپازیتوری را انتخاب کنید
4. تنظیمات ساخت لازم نیست (سایت استاتیک تک‌فایلی است) → Deploy
5. آدرس رایگان Netlify را می‌گیرید؛ هر بار که در GitHub تغییر بدهید، Netlify خودش دوباره منتشر می‌کند

### راه ۳ — Vercel

مشابه راه ۲، ولی در `vercel.com` با GitHub وارد شوید و همان ریپازیتوری را Import کنید. برای نسخه استاتیک، Vercel هم شماره موبایل برای تایید می‌خواهد؛ اگر پیامک نرسید، Netlify را امتحان کنید.

## تست سریع (۵ دقیقه)

1. سایت را باز کنید → پنل معلم → رمز تعیین کنید
2. یک تکلیف آزمایشی بسازید: «تکلیف آزمایشی — طرحی از طبیعت»، پایه هفتم، کلاس الف، مهلت ۳۰ آبان ۱۴۰۵
3. به‌عنوان دانش‌آموز ارسال کنید و کد پیگیری را کپی کنید
4. در پنل معلم نمره ۱۸ بدهید، روی عکس یک نشانه بگذارید، اثر را منتخب کنید
5. در پیگیری با کد، نمره و نشانه را ببینید؛ در دیوار آثار چک کنید توضیح خصوصی و نمره نیست
6. ارسال و تکلیف آزمایشی را حذف/آرشیو کنید تا سایت تمیز بماند
